
# Jaguar Quantum Chemistry Module

## DFT Calculations
Jaguar provides density functional theory (DFT) capabilities for electronic structure calculations.

## Running Jobs
Submit jobs via the command line:
```bash
jaguar run job.inp -wait -local
```

## Key Keywords
Theory DFT
Functional B3LYP
Basis 6-31G*
Charge 0
Multiplicity 1
Solvent Water
Grid UltraFine

## Memory Settings
-memory 16GB
-nproc 8
